# Trainer verification runs

Every training run made while building and verifying the trainer, on an NVIDIA GB10 (DGX Spark) shared with other
programs, 2026-10-01. Generated by `training_research/trainer_verification/summarise_runs.py` from each run's
`result.json`.

- **test accuracy %**: right on examples set aside before training, before → after.
- **guard change**: the change on general questions the run never trained on, in points, with the probability that
  it is a real drop (`p_worse`).
- **attempts**: 2 when the first attempt forgot general decisions and the trainer retried more gently.
- **parity**: the largest difference between the saved fine-tune, loaded the way the studio serves it, and the trained
  model (blank when the run was made with `--no-parity`).
- **overrides**: recipe settings changed for an experiment; rows without overrides used the defaults of the time.
  Early Julia rows (`julia-capsotu-*`, `julia-abl-*`, `julia-r*`) are the experiments that settled Julia's recipe;
  the `final2` rows and the rows in [docs/testing.md](../testing.md) use the shipped defaults. Rows named by date are
  trainings started from the Train page.
