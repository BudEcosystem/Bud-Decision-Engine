Bud Decision Studio documentation

Bud Decision Studio runs open decision models on your own computer. You describe a situation, ask questions about it, and get calibrated probabilities back, with every decision kept in a history you can review. Start in the app, or call it from your code.

Use the app

  • Install the studioWindows, macOS and Linux, and what your computer needs.
  • Ask your first questionLoad a model, describe a situation and read the answer.
  • Save it as a templateReuse the same questions with new details each time.
  • Review what was decidedEvery decision, what the model saw, and what needed a person.
  • Choose a modelThe eleven models, what each is good at and the memory it needs.
  • Teach it your decisionsTrain a model on your own examples; keep it only if it got better.

Build with the API

  • Call the studio from your codeSend a situation and questions, act on the answers.
  • DecisionsCreate, wait for, rerun, label and redact decisions.
  • TemplatesVersions, aliases and safe changes from a script or CI.
  • Move from Jev or a gatewayChange the base URL; your SDK code keeps working.
  • ErrorsEvery error code, what causes it and how to fix it.
